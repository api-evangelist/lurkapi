LurkAPI provides social media data APIs that enable AI applications to access posts, ads, and profiles from sixteen major platforms. The service offers clean JSON outputs for ads, posts, and user profiles, with flexible pricing per call and no subscription required. It supports tools for searching, retrieving, and analyzing social content across Facebook, Instagram, Reddit, YouTube, TikTok, Google News, and more, helping developers integrate real‑time social insights into their products.

**Areas:** Social Media · Data API · AI Integration · Advertising · Analytics

- [LurkAPI Snapchat API](https://apis.io/apis/lurkapi/lurkapi-snapchat-api/) — Public profiles, live stories, highlights and Spotlight videos from Snapchat.

- [LurkAPI YouTube API](https://apis.io/apis/lurkapi/lurkapi-youtube-api/) — Videos, Shorts, transcripts, comments and channel stats from any public YouTube channel.
- [LurkAPI Linked In API](https://apis.io/apis/lurkapi/lurkapi-linked-in-api/) — Public profiles, company pages and their updates, job listings, and ads from LinkedIn's Ad Library.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for LurkAPI: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
